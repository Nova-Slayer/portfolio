06 — Colophon

How this was made.

Notes on type, color, and the craft behind it.

Typefaces
Instrument Serif for editorial voice · Inter Tight for structure · JetBrains Mono for code
A classic-modern pairing. The italic serif carries the personality; the sans carries the reading; the mono carries the precision.
Palette
Electric lime (#D4FF4F) on ink black (#050505)
One accent, used sparingly. The lime is a signal — never decoration. Everything else is grayscale to let the type breathe.
Method
Hand-coded vanilla HTML, CSS, and JavaScript
No frameworks, no build tools, no dependencies beyond a font and an icon set. Every animation is on GPU-friendly transforms.
Motion
Scroll-driven reveals with blur + slide
Elements fade in with a soft blur instead of a hard cut. Sections arrive as sentences do — gradually, with intent.
Grid
Editorial asymmetric layout
Hairline rules, numbered sections, and typographic hierarchy borrowed from magazine design. The layout is a system, not a template.
